> **참조 에이전트:** Artisan (정본), Architect (참고)
> 화면 목록, 라우트, 내비게이션 구조, 레이아웃 와이어프레임을 정의한다.

## 1. Navigation Structure

### 1.1. 전체 구조

```
App
├── SplashScreen (/splash)
├── OnboardingScreen (/onboarding)  ← 최초 1회
└── MainShell (BottomNavigation)
    ├── Tab 0: HomeScreen (/home)
    ├── Tab 1: StockListScreen (/stock)
    ├── Tab 2: RecipeScreen (/recipe)
    └── Tab 3: ColumnListScreen (/column)
```

### 1.2. 바텀 네비게이션 탭

| Index | 라벨 | 아이콘 | Route | Phase |
|-------|------|--------|-------|-------|
| 0 | 홈 | `home_rounded` | `/home` | 1.0 |
| 1 | 냉장고 | `kitchen_rounded` | `/stock` | 1.0 |
| 2 | 레시피 | `restaurant_menu_rounded` | `/recipe` | 1.1 |
| 3 | 칼럼 | `auto_stories_rounded` | `/column` | 2.6 |

> 아이콘 매핑: `brand-assets §4.2`. Material Symbols Rounded, 24dp.

### 1.3. go_router 설정

```dart
// lib/router/app_router.dart
// ShellRoute로 BottomNavigation 감싸기
// 탭 간 전환: fast (200ms) 크로스페이드
// 하위 화면 전환: normal (300ms) easeInOutCubic
// 모달/바텀시트: normal (300ms)
```

## 4. Responsive Breakpoints

| 카테고리 | 너비 | 레이아웃 |
|---------|------|----------|
| 소형 폰 | < 360dp | 1열 리스트, 축소 카드 |
| 일반 폰 | 360~414dp | **기본 디자인 기준** |
| 대형 폰 | 414~600dp | 레시피 카드 2열 그리드 |
| 태블릿 | > 600dp | Phase 2+ 대응 예정 |
