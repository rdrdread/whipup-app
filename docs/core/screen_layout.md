## 1. Navigation Structure

### 1.1. 전체 구조

```
App
├── SplashScreen (/splash)
├── OnboardingScreen (/onboarding)  ← 최초 1회
│   ├── 시작하기 → StorageSetupScreen
│   └── 건너뛰기 → 기본 구성 자동 추가 → HomeScreen
├── StorageSetupScreen (/storage-setup)  ← 온보딩 후 1회
└── MainShell (BottomNavigation)
    ├── Tab 0: HomeScreen (/home)
    │           ├── 대시보드 카드 (전체 보유 재료 + 임박)
    │           ├── 빠른 레시피 추천 (카드 슬라이더)
    │           └── 콘텐츠 (수평 스크롤)
    ├── Tab 1: StockScreen (/stock)
    │           ├── SubTab: 냉장고 (/stock?loc=fridge)
    │           ├── SubTab: 냉동고 (/stock?loc=freezer)
    │           ├── SubTab: 팬트리 (/stock?loc=pantry)
    │           └── SubTab: 서랍장 (/stock?loc=drawer)
    ├── Tab 2: RecipeScreen (/recipe)
    └── Tab 3: MyScreen (/my)
                ├── 활동 통계 (총 요리/등록 재료/시도 종류)
                ├── 나의 기록 링크
                ├── 칼럼 링크
                └── 설정 링크
```

### 1.2. 바텀 네비게이션 탭

| Index | 라벨 | 아이콘 | Route | Phase |
|-------|------|--------|-------|-------|
| 0 | 홈 | `home_rounded` | `/home` | 1.0 |
| 1 | 재고 | `kitchen_rounded` | `/stock` | 1.0 |
| 2 | 레시피 | `restaurant_menu_rounded` | `/recipe` | 1.1 |
| 3 | 마이 | `person_rounded` | `/my` | 1.0 |

> 아이콘 매핑: `brand-assets §4.2`. Material Symbols Rounded, 24dp.

### 1.3. 재고 화면 보관 위치 탭

재고 화면 상단에 **보관 위치 서브탭**을 배치하여, 재료가 물리적으로 어디에 있는지 직관적으로 구분한다.

| SubTab | enum 값 | 아이콘 | 설명 |
|--------|---------|--------|------|
| 냉장고 | `fridge` | 🧊 | 냉장 보관 식재료 |
| 냉동고 | `freezer` | ❄️ | 냉동 보관 식재료 |
| 팬트리 | `pantry` | 📦 | 상온 보관 (쌀, 통조림, 건조식품 등) |
| 서랍장 | `drawer` | 🧂 | 양념, 소스, 오일류 |

- 서브탭은 화면 상단에 **고정 탭 바** (TabBar)로 표시.
- 기본 선택: 냉장고.
- 서브탭 아래에 기존 카테고리 필터 칩이 위치.
- 서브탭 가로 규격: 각 탭은 **화면 너비의 1/4**을 균등 분할 (flex: 1). 고정 너비 사용 금지.
- 탭 내부 패딩: 상하 `sm` (8dp), 좌우 자동 (중앙 정렬).

### 1.4. go_router 설정

```dart
// lib/router/app_router.dart
// ShellRoute로 BottomNavigation 감싸기
// 탭 간 전환: fast (200ms) 크로스페이드
// 하위 화면 전환: normal (300ms) easeInOutCubic
// 모달/바텀시트: normal (300ms)
// 재고 서브탭: queryParam 'loc' (fridge/pantry/drawer)
```

## 4. Responsive Breakpoints

| 카테고리 | 너비 | 레이아웃 |
|---------|------|----------|
| 소형 폰 | < 360dp | 1열 리스트, 축소 카드 |
| 일반 폰 | 360~414dp | **기본 디자인 기준** |
| 대형 폰 | 414~600dp | 레시피 카드 2열 그리드 |
| 태블릿 | > 600dp | Phase 2+ 대응 예정 |
